       │                       │ 6. Lưu Alert vào DB ─────────────────────────►│             │

       │                       │       → Kiểm tra cooldown                    │             │
       │                       │       → Tạo alert_id (UUID)                  │             │
       │                       │       → Lưu DB ──────────────────────────────►│             │
       │                       │                                               │ alert saved │
       │                       │    e. WebSocket Broadcast ──────────────────────────────► │
       │                       │       {"type":"alert",                        │  REAL-TIME  │
       │                       │        "data":{attack_type:"DDoS",...}}       │  Live Feed  │
       │                       │                                               │             │
       │                       │ 4. Lặp lại cho 80 samples (2 rounds)         │             │
       │                       │    mỗi sample cách nhau 0.5 giây             │             │
       │                       │                                               │             │
       │  GET /api/demo/status  │                                               │             │
       │──────────────────────►│ 5. Trả về thống kê:                          │             │

        │                       │  2. GeoIP lookup      │                    │

        │                       │                       │ blacklist table     │
        │                       │  4. add_to_blacklist() ────────────────────►│
        │                       │                       │            in-memory set
        │                       │  5. Ghi BlockHistory ─►│                    │
        │                       │  6. Ghi AuditLog ─────►│                    │
        │  200 OK ◄─────────────│                       │                    │
        │                       │                       │                    │
        │  POST /api/geoblock/   │                       │                    │
        │  {country_code:"CN"}   │                       │                    │
        │──────────────────────►│  7. INSERT geo_block ─►│                    │
        │                       │                       │ geo_block_rules     │
        │                       │  8. add_geo_block() ───────────────────────►│
        │                       │                       │            geo_blocked set
        │  200 OK ◄─────────────│                       │                    │
        │                       │                       │                    │
        │                       │         Khi có gói tin từ IP bị block:      │
        │                       │                       │  _is_blacklisted()  │
        │                       │                       │  → True             │
        │                       │                       │  Alert bị suppress  │
        │                       │                       │                    │
        │                       │                       │  _is_geo_blocked()  │
        │                       │                       │  → lookup country   │
        │                       │                       │  → True → suppress  │
        │                       │                       │                    │
        │                  AUTO-BLOCK (không cần admin):                      │
        │                       │                       │  10+ alerts từ 1 IP │
        │                       │                       │  trong correlation  │
        │                       │                       │  window (60s)       │
        │                       │                       │  → _auto_add_to_blacklist()

        │                       │                       │  → add in-memory    │

■ Xanh đậm  = Điện thoại / Máy chủ con (agent)
