## 2. Required JSON Report Files

Attach the following files directly to the thesis appendix or GitHub repository `reports/` directory.

| File | Description | How to Generate |
|---|---|---|
| `reports/cicids2017_training_report.json` | Full training metrics: accuracy, precision, recall, F1, confusion matrix, FPR, model hyperparameters, class names, dataset shape | Run `scripts/train_cicids2017.ps1` with full CICIDS2017 CSV data |
| `reports/cicids2017_preprocess_report.json` | Preprocessing summary: rows loaded/kept/dropped, class distribution, missing column handling actions | Run `scripts/preprocess_cicids2017.py` |
| `reports/training_report.json` | Legacy training report (baseline model) | Generated by `backend/ml/training.py` |
| `models/features.json` | Canonical feature list (20 features, version, training date) | Auto-generated during training |

> **Important:** The current `reports/cicids2017_training_report.json` was generated on a minimal 8-row validation dataset. Before thesis submission, re-run the training pipeline with the full CICIDS2017 dataset to obtain representative metrics. The report schema is identical regardless of dataset size.

### Key Fields to Reference in Thesis Text

From `cicids2017_training_report.json`:
- `metrics.accuracy` — cite as overall classification accuracy
- `metrics.f1_macro` — cite as macro-averaged F1 (preferred metric for imbalanced classes)
- `metrics.false_positive_rate` — cite as FPR (critical for IDS evaluation)
- `metrics.confusion_matrix` — use to generate the confusion matrix heatmap chart
- `model_params` — cite hyperparameters in the methodology chapter
- `class_names` — list the attack categories the model can detect

### 4.3 Confusion Matrix Generation Script

```python
import json
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np

with open("reports/cicids2017_training_report.json") as f:
    report = json.load(f)

cm = np.array(report["metrics"]["confusion_matrix"])
labels = report["metrics"]["class_names"]

# Normalize by row (recall per class)
cm_norm = cm.astype(float) / cm.sum(axis=1, keepdims=True)

plt.figure(figsize=(8, 6))
sns.heatmap(cm_norm, annot=True, fmt=".2f", xticklabels=labels,
            yticklabels=labels, cmap="Blues")
plt.xlabel("Predicted Label")
plt.ylabel("True Label")
plt.title("Confusion Matrix — IDS Ensemble Model (CICIDS2017)")
plt.tight_layout()
plt.savefig("reports/confusion_matrix.png", dpi=150)
```
